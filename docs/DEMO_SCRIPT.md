# Demo video script

**Opening:** “From experiment to paper, without breaking provenance.” Show the live product immediately, choose **Experiments**, and click **Load demo lifecycle**.

**Experiment becomes evidence:** Compare Run #191 with completed Run #204. Show the changed metric, learning rate, result artifact, and source commit, then open one of Run #204's evidence records.

**Evidence becomes paper:** In Evidence, show the complete run → result → manuscript path. Use a result to create a linked claim, or link it to an existing manuscript object.

**New experiment breaks the paper:** Return to Paper. Show that the replacement run affects the claim, method, table, and figure, then open Research Diff.

**Research X-Ray:** Enter X-Ray and point out the one verified, three stale, and one contradicted objects. Jump from the summary to the contradicted 18.2% claim.

**Verify This:** Verify the 481,000-observation claim, then the incorrect 18.2% claim. Show the 16.8% evidence-backed contradiction and explain that ambiguous/conflicting evidence is surfaced for review rather than guessed through.

**Research Diff:** Open Research Diff. Rapidly show the result, learning-rate, table, and figure drift. Inspect the learning-rate change and stage it. Accept the visible CriticMarkup as the researcher and show the item reconcile.

**WebMCP:** Ask the connected agent to compare the two runs, retrieve the evidence catalog and research diffs, then navigate to the stale figure or method. Emphasize that the tools operate on the same live state and that the agent cannot accept its own rewrite.

**Close:** “Experiments produce evidence. Evidence supports the paper. Your agent can maintain the same workspace, but the researcher remains the author.”
